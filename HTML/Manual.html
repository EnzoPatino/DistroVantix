MANUAL DE COMANDOAS DE KALI LINUX

Conoce tus herramientas

Las herramientas que Manejamos en kali linux

Conocer tus herramientas es casi tan Importante como que un mecanico sepa Reparar un motor. Pero no es facil, Manejar tus herramientas adecuadamente Para eso tenes este manual, a tus manos

Comandos de Red

ifconfig: Para ver tu dirección IP y estado de las interfaces.

nmcli device: Para ver las tarjetas de red detectadas.

hostname -I: Tu IP local de forma rápida.

ip route: Muestra la tabla de rutas del sistema.

Paquetes y Actualización

sudo apt update: Busca nuevas versiones de herramientas.

sudo apt install (nombre): Para instalar herramientas nuevas.

sudo apt full-upgrade: Actualiza todo el sistema Kali.

systemctl start [servicio]: Inicia una herramienta (ej: apache2).

Exploración de Archivos Críticos:

cat /etc/os-release: Muestra info detallada de la versión de Kali que estás corriendo.

ls -la /home/: Lista todos los usuarios y archivos ocultos del sistema.

cat /etc/apt/sources.list: Verifica los repositorios de donde Kali baja sus herramientas.

Gestión de Herramientas:

apt remove [nombre]: Desinstala una herramienta que ya no necesites.

apt search [término]: Busca herramientas nuevas en los repositorios de Kali.

sudo apt autoremove: Borra paquetes viejos para liberar espacio en el disco.

Nmap - Escaneo de Red

nmap -sV [objetivo] - Escaneo de versiones

nmap -O [objetivo] - Detecta sistema operativo

nmap -p- [objetivo] - Escanea todos los puertos

Nmap - Avanzado

nmap -sS [objetivo] - Escaneo TCP SYN

nmap -sU [objetivo] - Escaneo UDP

nmap -A [objetivo] - Escaneo agresivo

Metasploit - Inicio

msfconsole - Inicia la consola

msfdb init - Inicializa la base de datos

db_status - Verifica el estado

Metasploit - Comandos

search [tipo]:[nombre] - Busca módulos

use [módulo] - Selecciona un módulo

show options - Muestra las opciones

Wireshark

wireshark - Inicia en modo gráfico

tshark - Modo línea de comandos

John the Ripper

john archivo.hash - Crackea contraseñas

john --show archivo.hash - Muestra crackeadas

unshadow passwd shadow > archivo - Combina archivos

Aircrack-ng

airodump-ng [interfaz] - Escanea redes WiFi

airodump-ng --channel [canal] --write [archivo] - Captura handshakes

aireplay-ng --deauth 0 -a [MAC] - Desautentica

SQLmap

sqlmap -u [URL] - Inicia análisis SQL

sqlmap -u [URL] --dbs - Lista bases de datos

sqlmap -u [URL] --dump - Extrae datos

Hashcat

hashcat -m [modo] -a [ataque] hash wordlist - Crackea

hashcat -m 0 hash wordlist - Crackea MD5

Netcat y Otros

nc -lvp [puerto] - Abre puerto en escucha

nc [objetivo] [puerto] - Conecta a objetivo

netstat -tulpn - Muestra puertos
