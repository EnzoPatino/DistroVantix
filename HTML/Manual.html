Documentación técnica de Kali Linux

KALI LINUX Y HERRAMIENTAS DE SEGURIDAD

Saber manejar las herramientas de tu entorno es fundamental para cualquier profesional de la seguridad. Sin embargo, memorizar tantos comandos o buscarlos individualmente puede ser un desafío. Por eso, en DistroVantix hemos preparado esta guía de referencia rápida.

DistroVantix - Guía de Referencia Rápida

Gestión de Red

ip a Muestra todas las interfaces y direcciones IP.

nmcli dev wifi Escanea redes WiFi cercanas desde terminal.

ifconfig [int] up/down Activa o desactiva una interfaz.

iwconfig Configuración específica de interfaces inalámbricas.

Mantenimiento

sudo apt update Sincroniza los repositorios de Kali.

sudo apt install [pkg] Instala nuevas herramientas de seguridad.

sudo apt full-upgrade Actualiza Kali a la última versión disponible.

systemctl start [serv] Inicia servicios (ej. postgresql o apache2).

Nmap - Escaneo

nmap -sS [objetivo] Escaneo TCP SYN (sigiloso).

nmap -sV [objetivo] Detecta versiones de servicios abiertos.

nmap -O [objetivo] Intenta identificar el Sistema Operativo.

nmap -p [puertos] Escanea puertos específicos (ej. -p 80,443).

Enumeración

whois [dominio] Información de registro de un dominio.

dig [dominio] Consultas detalladas a servidores DNS.

nslookup [IP] Resolución inversa de direcciones IP.

netdiscover -r [red] Descubrimiento pasivo de hosts en LAN.

Metasploit Framework

msfconsole Inicia el entorno de explotación.

search [exploit] Busca módulos por nombre o vulnerabilidad.

use [ruta/modulo] Selecciona un módulo para configurar.

set RHOSTS [IP] Define la dirección del objetivo.

Payloads y Ejecución

show options Muestra los parámetros necesarios.

set PAYLOAD [ruta] Define la carga útil (ej. reverse_tcp).

exploit / run Lanza el ataque contra el objetivo.

sessions -l Lista las conexiones activas (shells/meterpreter).

Ataques WiFi

airmon-ng start [int] Pone la tarjeta en modo monitor.

airodump-ng [int] Captura paquetes y visualiza redes.

aireplay-ng --deauth Desautentica usuarios de una red.

aircrack-ng [file.cap] Crackea la clave WPA/WPA2 capturada.

Análisis Web

nikto -h [URL] Escáner de vulnerabilidades en servidores web.

sqlmap -u [URL] Automatización de Inyección SQL.

dirb [URL] Fuerza bruta para encontrar directorios ocultos.

commix --url=[URL] Explotación de inyección de comandos.

Cracking

john [archivo] Crackea hashes de contraseñas locales.

hashcat -m [tipo] [hash] Cracking por GPU de alta velocidad.

hydra -l [user] -P [pass] Ataque de fuerza bruta a protocolos (SSH, FTP).

crunch [min] [max] Generador de diccionarios personalizados.

Análisis y Sniffing

wireshark Analizador de protocolos de red gráfico.

tshark Versión de terminal de Wireshark.

tcpdump -i [int] Captura tráfico de red en tiempo real.

binwalk -e [file] Extrae archivos ocultos dentro de binarios.
