Documentación técnica de Kali Linux

KALI LINUX Y HERRAMIENTAS DE SEGURIDAD

Saber manejar las herramientas de tu entorno es fundamental para cualquier profesional de la seguridad. Sin embargo, memorizar tantos comandos o buscarlos individualmente puede ser un desafío. Por eso, en DistroVantix hemos preparado esta guía de referencia rápida.

DistroVantix - Guía de Referencia Rápida

Gestión de Red

ip a Muestra todas las interfaces y direcciones IP.

nmcli dev wifi Escanea redes WiFi cercanas desde terminal.

ifconfig [int] up/down Activa o desactiva una interfaz.

iwconfig Configuración específica de interfaces inalámbricas.

Mantenimiento

sudo apt update Sincroniza los repositorios de Kali.

sudo apt install [pkg] Instala nuevas herramientas de seguridad.

sudo apt full-upgrade Actualiza Kali a la última versión disponible.

systemctl start [serv] Inicia servicios (ej. postgresql o apache2).

Nmap - Escaneo

nmap -sS [objetivo] Escaneo TCP SYN (sigiloso).

nmap -sV [objetivo] Detecta versiones de servicios abiertos.

nmap -O [objetivo] Intenta identificar el Sistema Operativo.

nmap -p [puertos] Escanea puertos específicos (ej. -p 80,443).

Enumeración

whois [dominio] Información de registro de un dominio.

dig [dominio] Consultas detalladas a servidores DNS.

nslookup [IP] Resolución inversa de direcciones IP.

netdiscover -r [red] Descubrimiento pasivo de hosts en LAN.

Metasploit Framework

msfconsole Inicia el entorno de explotación.

search [exploit] Busca módulos por nombre o vulnerabilidad.

use [ruta/modulo] Selecciona un módulo para configurar.

set RHOSTS [IP] Define la dirección del objetivo.

Payloads y Ejecución

show options Muestra los parámetros necesarios.

set PAYLOAD [ruta] Define la carga útil (ej. reverse_tcp).

exploit / run Lanza el ataque contra el objetivo.

sessions -l Lista las conexiones activas (shells/meterpreter).

Ataques WiFi

airmon-ng start [int] Pone la tarjeta en modo monitor.

airodump-ng [int] Captura paquetes y visualiza redes.

aireplay-ng --deauth Desautentica usuarios de una red.

aircrack-ng [file.cap] Crackea la clave WPA/WPA2 capturada.

Análisis Web

nikto -h [URL] Escáner de vulnerabilidades en servidores web.

sqlmap -u [URL] Automatización de Inyección SQL.

dirb [URL] Fuerza bruta para encontrar directorios ocultos.

commix --url=[URL] Explotación de inyección de comandos.

Cracking

john [archivo] Crackea hashes de contraseñas locales.

hashcat -m [tipo] [hash] Cracking por GPU de alta velocidad.

hydra -l [user] -P [pass] Ataque de fuerza bruta a protocolos (SSH, FTP).

crunch [min] [max] Generador de diccionarios personalizados.

Análisis y Sniffing

wireshark Analizador de protocolos de red gráfico.

tshark Versión de terminal de Wireshark.

tcpdump -i [int] Captura tráfico de red en tiempo real.

binwalk -e [file] Extrae archivos ocultos dentro de binarios.

Transferencia de Archivos

python3 -m http.server [puerto] Levanta un servidor web rápido para compartir herramientas o archivos.

curl -O [URL] Descarga un archivo directamente desde una URL a la terminal.

wget [URL] Descarga contenido o scripts de forma directa de internet.

scp [archivo] user@[IP]:[ruta] Copia archivos de forma segura entre máquinas mediante SSH.

Post-Explotación Básica

whoami && id Muestra el usuario actual y sus privilegios reales en el sistema.

uname -a Obtiene detalles del kernel y del sistema operativo víctima.

find / -perm -4000 2>/dev/null Busca archivos con permisos SUID (útil para escalada de privilegios).

history -c Limpia el historial de comandos de la sesión actual en la terminal.

Web: Mapeo y Fuzzing

gobuster dir -u [URL] -w [wordlist] Descubre directorios ocultos mediante fuerza bruta rápida.

wfuzz -c -z file,[wordlist] [URL]/FUZZ Fuzzing avanzado de parámetros, rutas y subdominios.

whatweb [URL] Identifica tecnologías, CMS, servidores y versiones de un sitio.

wpscan --url [URL] Escáner de seguridad especializado en buscar fallos en WordPress.

OSINT y Recon

theHarvester -d [dominio] -b all Recolecta correos, subdominios y nombres desde fuentes públicas.

sherlock [usuario] Busca perfiles activos de un mismo nombre en cientos de redes sociales.

dnsrecon -d [dominio] Automatiza la enumeración completa de registros DNS de un objetivo.

subfinder -d [dominio] Herramienta rápida para descubrir subdominios válidos de forma pasiva.

Pivoting y Túneles

ssh -L [puerto_l]:[target]:[puerto_r] user@[IP] Redirección local de puertos (Local Port Forwarding).

chisel server -p [puerto] --reverse Inicia el servidor de Chisel para túneles inversos.

socat TCP-LISTEN:[p1] TCP:[IP]:[p2] Redirige de forma bidireccional tráfico entre redes.

proxychains [comando] Enruta cualquier herramienta (ej. nmap) a través de proxies SOCKS.

Evasión y Utilidades

msfvenom -p [payload] -e [encoder] -f exe Genera cargas útiles aplicando codificación (encoders).

strings [archivo] Extrae e imprime el texto legible que está oculto dentro de un binario.

impacket-smbserver [nombre] [ruta] Monta un servidor SMB compartido para interactuar con sistemas Windows.

nc -lvnp [puerto] Escucha conexiones entrantes (esencial para recibir reverse shells).

Servicios del Entorno

msfdb init Inicializa la base de datos local para acelerar búsquedas en Metasploit.

systemctl start postgresql Levanta el gestor de base de datos requerido por las herramientas.

kali-tweaks Menú interactivo en terminal para configurar repositorios y el sistema.

systemctl start gvm Inicializa el entorno gráfico de Greenbone Vulnerability Manager (OpenVAS).

Metapaquetes de Kali

sudo apt install kali-linux-everything Descarga e instala el repertorio completo de herramientas de Kali.

sudo apt install kali-tools-headless Instala todas las utilidades de consola que no requieren GUI.

sudo apt install kali-tools-wireless Actualiza el set completo para auditorías inalámbricas.

kali-undercover Modifica la interfaz para simular un entorno Windows en un segundo.
